# 大学生学术数据囤积行为问卷

面向大学生的学术数据囤积行为自测：33 道陈述题，答完即时给出资料获取、保存、整理与使用上的行为剖面、类型特点，以及可照着做的改善建议。

在线访问：https://yaofzu.github.io/academic-material-quiz/

## 什么是学术数据囤积行为

在学习与研究中持续、过量地获取和保存数字学术资料（文献、课件、笔记、代码、数据集、参考链接），却很少整理、检索和真正使用。关键不在于存量多少，而在于存下来的和真正用上的差多远。

- 常见表现：收藏夹与下载文件夹持续膨胀；同一份文献存多个版本；一搜到就先保存。
- 主要成因：怕漏掉重要信息的焦虑、任务压力下的被动收集、缺少命名与归档习惯。
- 可能影响：找资料变慢、认知负担变重、对已有资料越来越没把握。

数字囤积在学界尚无统一定义，本问卷按“过度保存—低使用”的行为特征做探索性测量，结果供自我反思，不作诊断。

## 技术与说明

- 纯静态单页，`index.html` 即全部内容，无需构建、无外部依赖。
- 所有计分与结果计算都在浏览器本地完成，不提交、不上传任何作答数据，关闭页面即清除。
- 当前为研究试用版：从信息质量、技术促进两个维度中分别拟删原第 18、20 题，共 33 题；各维度按保留题目取均分，结合三类模型给出最接近的剖面。
- 旧数据按题号编码，未能确认当时是否删除这两题；建模所用导出记录存在重复模式。本版适合体验流程与自我反思，正式发放前需核对题目与模型，并用独立答卷验证。
