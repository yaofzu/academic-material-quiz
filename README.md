# 学术资料整理自测

面向大学生的学术资料整理自测问卷：33 道陈述题，答完即时给出资料整理行为剖面、特点说明和可照着做的整理建议。

在线访问：https://yaofzu.github.io/academic-material-quiz/

## 说明

- 纯静态单页，`index.html` 即全部内容，无需构建、无外部依赖。
- 所有计分与结果计算都在浏览器本地完成，不提交、不上传任何作答数据，关闭页面即清除。
- 当前为研究试用版：从信息质量、技术促进两个维度中分别拟删原第 18、20 题，共 33 题；各维度按保留题目取均分，结合三类模型给出最接近的剖面。
- 旧数据按题号编码，未能确认当时是否删除这两题；建模所用导出记录存在重复模式。本版适合体验流程与自我反思，正式发放前需核对题目与模型，并用独立答卷验证。
